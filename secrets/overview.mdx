KryptoVault **Secrets Management (Key Vault)** provides a centralized capability for securely organizing, protecting, and managing application secrets across controlled vaults.

It combines Vaults, Secrets, Protection Keys, version management, access controls, expiry rules, and audit settings into a common secrets-management model.

## Vault and secret model

KryptoVault uses a hierarchical model for secret management.

<Steps>
  <Step title="Protection Key">
    A Protection Key is created and made available for use by a Vault.
  </Step>
  <Step title="Vault">
    A Vault is created as the secure logical container and is linked to a Protection Key.
  </Step>
  <Step title="Secret">
    Secrets are created inside the Vault and inherit the relevant vault-level controls.
  </Step>
  <Step title="Versions">
    Each Secret maintains one or more versions, with one version acting as the default at a time.
  </Step>
</Steps>

<Info>
  A Secret belongs to one Vault. The Vault provides the management boundary, while Secret versions maintain the history of the protected value.
</Info>

## Operational controls

Vault configuration allows organizations to define how secrets are handled within each vault.

These controls include secret-version limits, mandatory expiry, response wrapping, network access restrictions, and audit-event behavior.

This allows different Vaults to be configured according to the operational requirements of the secrets they contain.

## Secret lifecycle visibility

KryptoVault maintains the operational context of secrets as they are created and updated.

Secret records can retain information such as type, environment, expiry, active version, total versions, and system-generated metadata.

Version management provides continuity as secret values change over time without replacing the Secret's identity.

## Security and auditability

Secrets Management keeps sensitive values protected while maintaining operational traceability around Vault, Secret, and Version activity.

Vault-level audit settings determine whether successful and failed requests generate audit events, helping teams maintain visibility into secret-management activity.

## Why it matters

KryptoVault Secrets Management helps organizations centralize secret storage, reduce uncontrolled credential handling, maintain version and expiry discipline, and apply consistent protection and access controls across application secrets.
