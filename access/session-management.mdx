KryptoVault **Session management** provides visibility and control around authenticated user sessions.

## Login activity

After successful authentication, the user can access the KeyManager portal according to account status and assigned access.

User profile information includes recent login activity, with the latest five login records available for visibility.

## Logout

Users can explicitly log out of KeyManager.

<Steps>
  <Step title="Initiate logout">
    The user selects the logout action.
  </Step>
  <Step title="Confirm logout">
    KeyManager asks for confirmation before ending the session.
  </Step>
  <Step title="Return to login">
    After confirmation, the user is returned to the login screen.
  </Step>
</Steps>
