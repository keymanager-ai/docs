KryptoVault **Password Policy** defines password validation for local authentication, first-login password setup, and password changes.

<Info>
  Passwords must contain 8–16 characters and include uppercase letters, lowercase letters, numbers, and special characters.
</Info>

## Password requirements

<CardGroup cols={2}>
  <Card title="Length" icon="ruler">
    Passwords must contain between 8 and 16 characters.
  </Card>

  <Card title="Character Mix" icon="keyboard">
    Passwords must include uppercase letters, lowercase letters, numbers, and special characters.
  </Card>
</CardGroup>

## Initial password setup

Administrators can require a user to set a new password after the user's first successful login.

<Steps>
  <Step title="User authenticates">
    The user successfully signs in with the credentials assigned during account creation.
  </Step>
  <Step title="Set Password is required">
    When the Set Password option is enabled, the user is taken to the password setup flow.
  </Step>
  <Step title="New password is validated">
    The new password must satisfy the password format and confirmation requirements.
  </Step>
  <Step title="Continue to KeyManager">
    After successful password setup, the user proceeds into the application.
  </Step>
</Steps>

## Change password

Logged-in users can change their local password through the Change Password capability.

The current password must be validated before the new password is accepted.

<Warning>
  The new password cannot be the same as the existing password, and the confirmation value must match the new password.
</Warning>

## Password visibility

Password fields support masked and unmasked entry during password setup and change flows.
