KryptoVault **Self Service** provides an additional entry point for authorized users to initiate certificate requests without working directly through the main CSR administration flow.

Requests initiated through Self Service are connected with the same CSR management model used within Certificate Management.

<Info>
  Self Service does not create a separate certificate-request lifecycle. Requests initiated here become part of the centralized CSR lifecycle in KryptoVault.
</Info>

## Self-service certificate requests

Self Service allows certificate-request activity to begin from a simplified request entry point while keeping the resulting request centrally managed.

## Request flow

Self Service connects directly with the CSR lifecycle.

<Steps>
  <Step title="Request initiated">
    An authorized user starts a certificate request through Self Service.
  </Step>
  <Step title="CSR created">
    The request becomes part of KryptoVault CSR management.
  </Step>
  <Step title="CSR lifecycle tracked">
    The request is tracked through the same CSR states used for directly created certificate requests.
  </Step>
  <Step title="Certificate produced">
    When the request results in a signed certificate, that certificate can continue into Certificate Inventory.
  </Step>
</Steps>

## Common CSR lifecycle

Self-service requests and directly created CSRs follow the same request lifecycle.

The confirmed CSR states include:

- Created
- Validating
- Submitted
- Signed
- Imported
- Rejected
- Cancelled

This keeps certificate-request tracking consistent regardless of where the request originates.

## Relationship with Certificate Management

Self Service acts as an entry point into the broader certificate-management lifecycle.

**Self Service → CSR → Signing → Certificate → Certificate Inventory**

This allows request initiation to be delegated while keeping CSR tracking and certificate management centralized within KryptoVault.

## Request and certificate lifecycle separation

The Self Service request becomes part of the CSR lifecycle first.

Once a certificate is successfully produced, the certificate itself is managed separately through Certificate Inventory and its own lifecycle.
